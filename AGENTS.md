# AGENTS

The following principles should be followed closely when working on this project.

## Frontend Principles
- Prefer minimalism and simplicity.
- Use modular primitives and components as much as possible; no/very minimal bespoke design.
- Prefer elegant mathematical relationships (ratios, etc.) over hardcoded values.
- Go for a clean glass aesthetic.

## Testing Principles
- As many unit tests as possible.
- As many integration tests as possible.
- A core set of fundamental E2E tests covering main user experience. Aim for high-quality testing, non-flaky.
- A large set of exploratory E2E tests, to thoroughly test the app, discover bugs, etc. These tests should be used for exploration and testing, not as criteria (not essential to pass).
